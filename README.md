# Airplane Ticket Reservation System
A full-stack airline ticket reservation system developed as an individual project for CSC 440: Applied Software Engineering at Eastern Kentucky University.

## Project Overview
This application allows users to search for available flights, create accounts, select seats, and manage airline reservations through a web-based interface.
The project demonstrates full-stack software development, REST API integration, relational database management, and software engineering design principles.

## Technologies Used
**Frontend**
- Angular
- TypeScript
- HTML
- CSS
**Backend**
- Python
- Django REST Framework
**Database**
- PostgreSQL
**External API**
- Duffel API — Flight search and availability
**Development Tools**
- Git and GitHub
- Postman
- Visual Studio Code

## Features
- User registration and login
- Flight searching using the Duffel API
- Flight availability and pricing information
- Passenger information management
- Seat selection
- Reservation creation
- Viewing existing reservations and flight tickets
- Editing and canceling reservations
- Changing flights
- Reservation modification restrictions within seven days of departure

**Current Limitation:** 
Reservation booking and seat selection currently support nonstop flights only.
